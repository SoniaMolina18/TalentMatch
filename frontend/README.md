# TalentMatch Frontend

Frontend E1 con React, TypeScript, Vite y React Router.

## Desarrollo

1. Instalar Node.js LTS.
2. Ejecutar `npm install`.
3. Copiar `.env.example` a `.env.local` si se desea cambiar la API.
4. Ejecutar `npm run dev`.

Durante el desarrollo, Vite redirige `/api` a `http://localhost:5000` para evitar cambios en CORS del backend.
